# AGENTS.md

Este repo es un catálogo de skills: el contenido es texto que leen otros agentes, así que una referencia desactualizada (un campo renombrado, un paso que ya no existe, una regla que contradice a otra skill) rompe el flujo sin dar error.

Al terminar una tarea que crea o modifica archivos en `skills/`, `docs/` o `README.md`, recordale al usuario que corra `/claude-api prompt-audit` en Claude Code para detectar esas inconsistencias antes de commitear.
